# Waylate v0.1.9 — per-translation AI follow-ups

- The source text field is the AI context. The optional context checkbox has been removed.
- **Explain text** works without a separate question. Questions can be entered initially or as follow-ups.
- The question field stays below the conversation, with a compact send control.
- Translation errors remain visible alongside translator controls; duplicate bottom status/model cards are removed.
- Default system prompt now requests short plain-text answers without Markdown. Existing custom prompts are preserved.
- Each translation has its own in-session conversation, including previous questions/answers.
- A different text, language direction, model or API URL has a separate conversation.
- Conversation history is memory-only and bounded to 20 recent threads / six exchanges per thread, and is cleared on restart.
- No automatic network requests or changes to translation history, vocabulary, API keys or system prompts.
- EN/RU/SK interface copy updated. Previous features remain available.

## Compatibility and privacy

OpenAI-compatible API support is provider dependent. Remote APIs can receive the selected text, previous conversation turns and new questions when the user explicitly submits. Waylate does not send anything while simply selecting text. Do not use consumer OAuth token proxies if provider terms forbid this access. Ollama / permitted developer API endpoints are supported where they implement non-streaming chat completions.
