# Waylate v0.1.8 — release notes

Waylate now combines popup translation with an optional AI question assistant for language study.

## New
- Connect to one user-configured OpenAI-compatible chat endpoint (cloud via HTTPS, or local loopback HTTP), with an optional API key stored in your system keychain.
- Discover available model IDs through `GET /v1/models` when supported, or enter a model ID manually.
- Click **Test model** for an explicit non-streaming generation probe; this can incur API usage charges.
- Ask questions about words, expressions, sentences and arbitrary topics. Include or exclude the current source text as context. Answers appear separately from translations and remain outside the translation history.
- Set a persistent custom system prompt; `{target_language}` inserts the current translation target language. The AI interface and fields are hidden when the feature is disabled.
- Customize request timeout; errors for authentication, missing endpoints, rate limits, server failures and invalid responses are shown without exposing credentials. UI labels are available in English, Russian and Slovak.

## Compatibility and privacy
- **Disabled by default.** Existing translation models, dictionaries, vocabulary, paths, autostart, local history and API keys remain unchanged.
- No background AI requests, automatic retries or extra daemon; remote providers may charge and process submitted text.
- Supports a subset of OpenAI-compatible APIs: non-streaming `/chat/completions` plain-text responses. Does not promise compatibility with every provider.
- Do not use Google Antigravity consumer account/OAuth via third-party proxies; Google's terms forbid it. Use a provider's officially supported API keys instead.
- Anki integration is planned but **not** part of this release; existing vocabulary export remains available.

## Install
Download the published `Waylate-0.1.8-x86_64.AppImage` and its `.sha256` sidecar, verify using `sha256sum -c`, and start the AppImage. Existing Waylate settings and saved words should remain intact. Consult README for requirements.
