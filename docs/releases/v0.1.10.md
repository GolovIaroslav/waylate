# Waylate v0.1.10 — PDF copy and selection fix

Fixed artificial PDF line breaks that made selected words appear one per line in the translator.

- **Selected text / PRIMARY:** join words separated by newline or empty lines and repair words split by a hyphen at the end of a PDF line.
- **Copied text / clipboard:** join wrapped lines and detect the characteristic word-per-line PDF pattern. Regular paragraphs remain separated for ordinary copy-paste content.
- The same normalization is used by the KDE selection shortcut, the translate-clipboard command, the clipboard fallback, and the tray's clipboard action.
- Tests cover English and Cyrillic examples, PDF whitespace, hyphenation and genuine paragraphs.
- No changes to saved AI providers, model IDs, API keys, translation history, local dictionary, or autostart.

The application does not modify the PDF itself or rewrite the system clipboard. This patch restores intended selection handling in the published binary.

## Verification

Automated Rust and frontend checks are run before release. Manual GUI interaction is not performed automatically.
